# Belis

Belis is a full-stack web application designed to help users create and manage strong brand identities through structured workflows and analysis tools.

## Tech Stack
- Frontend: React, Vite, Tailwind CSS
- Backend: Node.js, Express
- Database: MySQL

## Features
- Brand identity creation system
- Project-based workflow
- Identity analysis tools

## Setup

### Frontend
cd frontend
npm install
npm run dev

### Backend
cd backend
npm install
npm start

## Database
Import `brandforge.sql` into your MySQL server before running the backend.
